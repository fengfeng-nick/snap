# 显影室 Instant Lab

纯前端拍立得照片生成器。照片只在浏览器本地解码、处理和导出，不会上传到服务端。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 检查

```bash
pnpm typecheck
pnpm test
pnpm build
```

## 技术栈

- Vite
- React + TypeScript
- Tailwind CSS
- Canvas 2D

示例照片来自 [Unsplash](https://unsplash.com/photos/b586d89ba3ee)，仅用于应用的初始体验，用户选图后会被本地照片替换。
